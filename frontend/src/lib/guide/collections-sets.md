# Collections & Sets

Collections group related sets. Sets are the primary unit of data — an organisation, a project, a domain.

## Collections

A collection holds any number of sets. Browse the list at `/collections` to see every collection with its set count, package count, and diagram count. Click a collection to scope the whole app to its contents.

![Collections](/guide/collections.png)

## Sets

Sets live inside (or alongside) collections. Visit `/sets` for a flat list across every collection. Click a set to jump to its contents: packages, diagrams, and elements.

![Sets](/guide/sets.png)

## The "Default" set

Every Iris instance has a built-in **Default** set that contains anything not assigned to another set. You can't delete it.
