# Getting Started

Iris is a knowledge-graph and modelling tool for managing collections of organisations, their strategy diagrams, and the relationships between them.

## Read-only by default

You are viewing Iris in **read-only mode**. You can browse every collection, set, package, diagram, and element; run searches; open the knowledge graph; and ask the AI questions about content you see — without signing in.

To create, edit, or delete anything, use the **Sign in** link in the top-right corner.

![Iris dashboard](/guide/dashboard.png)

## The hierarchy

Iris organises content in five layers:

1. **Collections** — top-level groupings (e.g. "DoView Strategy Models").
2. **Sets** — a member of a collection (e.g. "NZ Government").
3. **Packages** — containers within a set (e.g. a strategy diagram tree).
4. **Diagrams** — individual diagrams within a package.
5. **Elements** — shapes and relationships on each diagram.

Each layer is covered in its own section of this guide. Use the nav bar on the left.
