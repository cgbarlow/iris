# Packages & Diagrams

Packages are nested containers within a set. Diagrams are the canvas-based artefacts that live inside packages.

## Package hierarchy

A set can have many top-level packages, and each package can contain sub-packages, diagrams, and relationships to other packages. The **Packages** list page shows a flat list with parent/child hover; clicking a package opens its tree view.

![Packages](/guide/packages.png)

## Diagrams

A diagram is a visual model — a DoView strategy diagram, a process flow, a schema. Iris stores canvas nodes, edges, element references, and package references on each diagram.

![Diagrams](/guide/diagrams.png)

## Diagram types

Iris supports multiple notations: DoView, BPMN, ArchiMate, generic flowcharts, and more. The type of each diagram is shown on its card and in the top-right corner of the canvas.
