# Keyboard Shortcuts

Iris is designed to be fully usable from the keyboard. These shortcuts work anywhere in the app unless noted.

## Canvas (inside a diagram)

| Shortcut | Action |
|---|---|
| `Tab` / `Shift+Tab` | Navigate between canvas elements |
| Arrow keys | Move selected element (hold `Shift` for larger steps) |
| `Ctrl+N` | Create a new element |
| `C` | Toggle connect mode to draw relationships |
| `Delete` | Delete selected element |
| `Escape` | Deselect or cancel the current operation |
| `Ctrl+=` / `Ctrl+-` | Zoom in / out |
| `Ctrl+0` | Fit canvas to screen |

## Global navigation

Every item in the left sidebar has a single-letter shortcut shown on hover. Press the letter to jump to that section.

| Shortcut | Section |
|---|---|
| `A` | Iris AI |
| `H` | Dashboard (Home) |
| `C` | Collections |
| `T` | Sets |
| `M` | Views (Diagrams + Text) |
| `E` | Elements |
| `G` | User Guide |
| `B` | Bookmarks (signed-in only) |
| `I` | Import (signed-in only) |
| `R` | Recycle Bin (signed-in only) |
| `S` | Settings (signed-in only) |

## Accessibility

Iris targets WCAG 2.2 Level AA. Every canvas operation has a keyboard equivalent. Use the theme toggle in the header to switch between light, dark, and high-contrast modes.
